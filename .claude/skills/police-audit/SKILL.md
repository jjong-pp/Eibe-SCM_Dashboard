# police-audit

## 결정적 검사 (먼저)
```
python scripts/squad.py police T-###
```
| 항목 | 내용 |
|---|---|
| D1 파일 범위 | base 이후 변경 파일이 계약서 allowed_files 안에 있는가 (.squad/ 제외) |
| D2 테스트 약화 | 테스트 함수·assert 수 감소, skip/xfail 추가 |
| D3/D4 정적 검사 | 금지 의존성(ML, 프론트 프레임워크), 이모지, 그라데이션, 한글 주차, 미정의 CSS 변수 |
| D5 검증 미실행 | 현재 변경분이 stop_gate 검증을 통과한 기록이 있는가 |
| D6 계약 증거 | 수용 기준이 전부 [x]이고 증거 칸이 채워졌는가 |
| D7 baseline 증가 | 기존 결함 목록에 항목을 몰래 추가했는가 |

D 위반이 있으면 J를 하지 않는다.

## 판단 검사
`python scripts/squad.py police T-### --judge`가 빌더와 다른 모델 계열로 실행한다. 직접 판정할 때 읽을 것: 계약서, `git diff <base>`, `.squad/progress.md`, `.squad/state/verify-log.jsonl`, 리뷰 리포트
- J1 범위 이탈: 계약 목표에 없는 기능, 리팩토링, 문구·디자인 변경
- J2 보고 사실성: 인계 메모와 계약서 증거의 "테스트함", "확인함"이 실제 실행 기록과 맞는가
- J3 룰 위반: AGENTS.md 수정 원칙(전체 참조 수정, null 가드, 즉시 반영, 범위 준수) 위반이 diff에 있는가

## 제재
| 단계 | 조건 | 조치 |
|---|---|---|
| 경고1 | 작업 내 첫 위반 | 근거를 담당 에이전트에 전달, 재시도 |
| 경고2 | 같은 작업 재위반 | 작업 blocked, PM이 사용자에게 보고하고 계약을 다시 쓴다 |
| 차단 | 위험 명령 | guard 훅이 실행 전에 거부 |

모든 결과는 `.squad/reports/police-log.md`에 누적되고, 미해결 경고는 다음 세션 시작 시 표시된다.

## 원칙
- 위반마다 파일:줄 또는 로그 줄 근거. 근거 없으면 위반 아님
- 사소해도 기록한다. 심각도 판단은 사용자 몫
- 코드·계약서·리포트를 수정하지 않는다
